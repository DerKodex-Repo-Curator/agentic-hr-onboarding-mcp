Logical Architecture

Intent to action flow
The prompt moves from the browser to Fastapi, through LangChain prompt parsing, into structured employee data.
Why this matters

The workflow now separates intake, runtime mode resolution, agent execution, cloud writes, and evidence generation so each business outcome is traceable.

Evidence by design

Each connector response writes an external id and URL into the ledger, while audit logs preserve the request and response behind the business evidence cards.
